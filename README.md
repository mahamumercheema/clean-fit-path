# FitTrack Launchpad

Create a simple, modern fitness website called FitTrack.

Build only a clean landing page with these sections:

Hero Section

Heading: "Your Fitness Journey Starts Here"

Short subtitle about tracking fitness, calories, and BMI.

Two buttons: "Calculate BMI" and "Get Started"

Features
Create 3 simple cards:

BMI Calculator

Calorie Calculator

Fitness Tracking

BMI Calculator
Add a simple calculator where users enter:

Height

Weight

Calculate and display their BMI with a basic category such as Underweight, Healthy, Overweight, or Obese.

Why FitTrack
A short section explaining that FitTrack helps users understand their fitness goals and stay consistent.

Footer
Include the FitTrack name and simple links: Home, Features, Contact.

Design:

Clean and minimal

Modern fitness aesthetic

White background with a simple green accent color

Rounded cards and buttons

Mobile responsive

Use simple animations only

No login, database, payment system, or external API

Keep the project lightweight and easy to maintain

Focus on making the website polished but simple rather than adding complex functionality.
